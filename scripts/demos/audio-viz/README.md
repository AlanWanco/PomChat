# 音频柱条 Demo

独立试验台，复用 PomChat 主题与聊天气泡组件。未接入正式编辑器的素材列表、项目保存、撤销或视频导出，不修改已有项目。

## 启动

在仓库根目录运行：

```bash
node scripts/audio-viz-demo.mjs --serve
```

打开 http://127.0.0.1:5199/ 。页面不会自动播放，请点击“播放”。

如需用同一局域网的手机或电脑查看：

```bash
node scripts/audio-viz-demo.mjs --serve --host 0.0.0.0 --port 5199
```

服务只提供 Demo HTML，不提供本机文件浏览或上传。没有身份认证，不要暴露到公网。

只构建离线单文件：

```bash
node scripts/audio-viz-demo.mjs
```

产物：`dist-test/audio-viz-demo/index.html`，可直接打开。该目录已被 Git 忽略。

## 可以试什么

- 播放内置的 12 秒合成节奏，或选择自己的音频。
- 在“柱条外观”中切换“滚动能量”和“跳动频谱”，播放不会中断。
- 滚动能量保留原来的横向历史效果；跳动频谱的柱子固定在原位，只上下升降。
- 两种模式分别记住生长方向；频谱初始为向上生长，能量初始为上下对称。
- 暂停、循环、拖动播放位置；同一时间点会得到同一组柱条。
- 调整颜色、数量、幅度、平滑时间、生长方向、宽高和透明度。
- 色彩模式支持单色或水平渐变；渐变可设置 2–5 种颜色，按列表顺序从左到右均匀分布在整排柱条上。
- “反向颜色”一键倒转渐变顺序，不用逐个重选；颜色数量保持不变。
- 两种色彩模式各自保留颜色设置，切换动画或边角不影响配色；重置恢复默认粉色单色。
- “柱条边角”可选圆角或直角，两种动画模式共用此设置；默认及重置后为圆角。
- 拖动选框移动柱条；选框支持方向键，滑块也可调整位置。
- 调整柱条相对文字标签、聊天气泡的遮挡顺序，或隐藏柱条。
- 切换中英文、明暗主题；移动端布局可纵向滚动。

## 数据与边界

- 内置音频是生成的节奏，不是示例气泡的对白，没有外部媒体。
- 滚动能量展示最近 0.6 秒的 RMS 能量，左右位置表示时间窗口，不表示频率。
- 跳动频谱使用 2048 点 Hann 窗 FFT，频段按对数排列，从左侧低频到右侧高频（正常采样率下约 60 Hz–10 kHz）。同一频段保持同一横坐标。
- 频谱按绝对时间取 PCM，60 Hz 分析帧之间插值，平滑只取固定的相邻时间窗口。不依赖播放顺序，也不会重新归一化每帧来制造跳动。
- 频谱合并各声道功率，反相立体声不会相消。缓存上限为 240 个分析帧，约 1 MB；音源替换后旧缓存可回收。
- Demo 为按需频谱保留解码后的 PCM，内存用量会高于只有能量包络的版本；沿用 5 分钟限制。
- 内置合成节奏只有三个主要音调，所以频谱集中在几组柱子；导入音乐或人声可看到更丰富的频段。
- 先在 PCM 上计算各声道功率，再压缩为每秒 120 个能量值，避免反相声道相消或先低采样导致高频能量丢失。
- 平滑结果随音源/平滑设置缓存；柱条按音频绝对时间取值，不累积播放状态。
- 试听音量不改变柱条幅度；“响应幅度”才控制柱条。
- 本机浏览器解码，导入不会上传。Demo 限制为 32 MB、5 分钟以内。
- 浏览器不能解码的格式会提示失败并保留原音源。本 Demo 没有 Electron FFmpeg 回退。
- 不保存设置，刷新后恢复默认；只有一个柱条实例和固定的文字/气泡对照层。
- `src/remotion/audioEnergy.ts`、`audioSpectrum.ts` 和 `AudioEnergyBars.tsx` 是可复用的计算/SVG 模块；它们尚未接入视频导出，不能将本次预览测试当成导出验证。
